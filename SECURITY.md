# Security Policy

## Supported Versions

Only the latest `1.x` release receives fixes.

## Reporting a Vulnerability

Report it through GitHub's private vulnerability reporting:
**[Open a private vulnerability report](https://github.com/anilcancakir/magic-starter-laravel/security/advisories/new)**

The report stays confidential until a fix is ready. Include the affected version, the Laravel and PHP versions, and the steps to reproduce.

## Scope

This policy covers the `anilcancakir/magic-starter-laravel` package:

- authentication tokens and sessions
- two-factor authentication
- social sign-in
- billing webhooks and entitlements
- profile photo uploads
- the published stubs

Issues in Laravel, Sanctum, Socialite, Filament and the other dependencies belong to their maintainers.
